# AI harness: quem faz o trabalho da IA

Vídeo explicativo com avatar e voz do Nei Maldaner (INEMA.CLUB), com todas as telas refeitas em português, produzido com o [Explicavideos v2](https://inematds.github.io/explicavideos/guia/) pelo método refazvideo.

**Assistir:** https://inematds.github.io/ai-harness/videos/

Duas versões com a mesma fala: **quadro branco** e **telas profissionais**.

O modelo sozinho é um cérebro num pote. Quem faz o trabalho no Claude Code e no Codex é o harness: contexto, memória, ferramentas, verificação e permissões, o loop do agente e o que vem por aí.

- `roteiro/pt.json`: fala e cenas
- `scripts/publica.py`: publica o vídeo (release + player)

Fonte: vídeo de Nick Saraev no YouTube. Conteúdo aberto e gratuito do [INEMA.CLUB](https://inema.club).
